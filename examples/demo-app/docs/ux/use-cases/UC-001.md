# UC-001 — Collaboration starts via invitation

**Scope.** From the lead's intent to add a colleague to the colleague being a
visible project member. The invitee's acceptance is represented by the status
badge in this demo (see product-intent assumptions).

**Trigger.** The lead has created a project and wants the team in it.

## Main flow

| # | Actor | System |
|---|-------|--------|
| 1 | Lead opens the project page | Shows members and the «Пригласить» action |
| 2 | Lead submits a colleague's e-mail | Validates format and duplicates |
| 3 | — | Confirms sending, adds the member with status «приглашён» |
| 4 | Colleague (out of demo scope) | Status would change to «участник» on accept |

## Extensions
- **2a.** Invalid format → inline error with example, input preserved.
- **2b.** Already a member → inline error, no duplicate, list unchanged.

## Postconditions
- Success: the member list reflects the invitation and its status.
- Failure: no state change; the lead has a visible way to correct and retry.
