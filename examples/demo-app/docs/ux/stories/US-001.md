# US-001 — Create a project

**Story.** As a team lead, I want to create a project so that my team has a
shared space to work in.

**Motivation.**
- Verified: demo requirement — the entry scenario of the product.
- Assumed: a name is the only thing a lead knows at creation time.

## Preconditions
- The app is open; no sign-in required (demo).

## Main success scenario
1. On the projects screen the lead presses «Новый проект» (or the empty-state CTA).
2. Enters a project name and submits.
3. Lands on the project page: title shown, themselves listed as «владелец»,
   and the interface suggests the next action — inviting colleagues.

## Alternative scenarios
- **A1 — first project:** the list is empty; the empty state explains the
  purpose and offers «Создать первый проект».

## Failure scenarios
- **F1 — empty name:** submit with no name → inline error explaining why the
  name matters; input stays editable; nothing is created.

## Acceptance criteria

```gherkin
Scenario: Create the first project
  Given the projects list is empty and shows the empty state
  When I press "Создать первый проект", enter "Альфа" and submit
  Then I see the project page titled "Альфа"
  And I see the note "Проект создан. Теперь пригласите коллег."

Scenario: Empty name is rejected with guidance
  Given the new project form is open
  When I submit without a name
  Then I see the error "Укажите название проекта — так коллеги поймут, куда их пригласили."
  And the form stays open
```
