# US-002 — Invite a colleague to a project

**Story.** As a project owner, I want to invite my colleague to a project so
that we can collaborate.

**Motivation.**
- Verified: demo requirement — the failure-handling scenario of the product.
- Assumed: email is how the lead identifies a colleague.

## Preconditions
- A project exists and the lead is on its page (US-001 completed).

## Main success scenario
1. On the project page the lead presses «Пригласить» — the action is visible
   next to the members list, where the result will appear.
2. Enters the colleague's e-mail and submits.
3. Sees confirmation naming the address, and the colleague appears in the
   members list with status «приглашён».

## Alternative scenarios
- **A2 — cancel:** «Отмена» closes the form without side effects.

## Failure scenarios
- **F1 — invalid email:** inline error with an example of a correct address;
  input preserved; form stays open.
- **F2 — already a member:** inline error stating the person is already in the
  project; no duplicate created.

## Acceptance criteria

```gherkin
Scenario: Invite a colleague successfully
  Given I am on the page of project "Альфа"
  When I press "Пригласить", enter "anna@team.ru" and submit
  Then I see "Приглашение отправлено на anna@team.ru" with a note about status
  And the members list shows "anna@team.ru" with status "приглашён"

Scenario: Invalid email is rejected with guidance
  Given the invite form is open
  When I submit "не-почта" as the address
  Then I see the error "Введите корректный e-mail, например kollega@company.ru."
  And the form stays open with my input preserved

Scenario: Existing member is not invited twice
  Given "anna@team.ru" is already a member of the project
  When I invite "anna@team.ru" again
  Then I see the error "Этот человек уже в проекте — приглашение не требуется."
  And the members list still shows one entry for "anna@team.ru"
```
